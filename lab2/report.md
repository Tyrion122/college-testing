Звіт до лабораторної роботи №2
Назва лабораторної роботи:
Основи програмування на Python, встановлення сторонніх бібліотек для роботи з PyTests.

Мета роботи:
Навчитися налаштовувати ізольоване тестове середовище у Python, опанувати розгортання структури проєкту, розробку модульних тестів, перевірку винятків, параметризацію, використання кастомних маркерів та створення фікстур із підготовкою й очищенням даних.

Виконання роботи:

створено структуру проєкту (каталоги src та tests) та ізольоване віртуальне середовище .venv;

використано фреймворк Pytest для написання тестів, параметризації та створення фікстур;

реалізовано тестове покриття для класу BankAccount (6+ тестів), що включає позитивні сценарії, перевірку винятків та параметризацію 

додано конфігураційний файл pytest.ini, глобальну фікстуру з yield у conftest.py та маркери пропуску тестів.

Висновок:
У результаті виконання лабораторної роботи налаштував структуру проєкту для тестування, розробив комплекс тестів для класу BankAccount, закріпив роботу з фікстурами, маркерами та параметризацією в Pytest.
